NSITEXE NS31A evaluation for Arty A7 board
########################

Overview
********

The NSITEXE NS31A for Arty A7 board configuration is used to evaluate NSITEXE Akaria NS31 series RISCV32 single core CPU.

Programming and Debugging
*************************

Applications for the ``nsitexe_ns31a_arty_a7`` board configuration can be
built and run in the usual way for Arty A7 boards (see :ref:`build_an_application` and
:ref:`application_run` for more details).

Debugging
=========

Refer to the detailed overview about :ref:`application_debugging`.
